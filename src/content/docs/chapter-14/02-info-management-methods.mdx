## 一、教学目标

掌握信息系统工程信息资料的分类方法（按性质、用途、载体、工程阶段），理解监理信息资料管理方法和文档编制策略。

## 二、核心讲解

### 1. 信息系统工程信息资料的划分

#### 1.1 按工程建设信息的性质划分

| 类型 | 说明 | 举例 |
|------|------|------|
| **引导信息** | 指导人们正确行为的技术经济活动 | 实施方案、实施组织设计、技术标准、规程、设计变更通知 |
| **辨识信息** | 认识事物性能、特征和效果 | 出厂证明书、技术合格证书、试验检验报告、验收签证 |

/>

#### 1.2 按工程建设信息的用途划分

| 用途类型 | 包含内容 |
|----------|----------|
| **投资控制信息** | 投资计划、投资估算、工程预算、费用支出凭证、工程变更、结算签证、物价指数 |
| **进度控制信息** | 总进度计划、分目标进度计划、实际完成工程量、进度比较信息 |
| **质量控制信息** | 质量检查数据、隐蔽验收记录、质量事故处理报告、质量体系文件 |
| **合同管理信息** | 合同法规、合同文本、合同执行情况、工程索赔 |
| **组织协调信息** | 工程调整指令、合同变更协议书、政府审批文件、法规标准 |
| **其他用途信息** | 往来函件等辅助决策信息 |

#### 1.3 按工程建设信息的载体划分

1. **文字信息** - 最主要的载体形式
2. **语言信息** - 会议记录、汇报等
3. **符号及图表信息** - 图纸、流程图、报表
4. **视频信息** - 监控录像、培训视频

#### 1.4 按工程阶段划分

| 阶段 | 内容 |
|------|------|
| 招标及准备阶段 | 投资前期决策信息、招标投标信息 |
| 设计阶段 | 设计方案、设计图纸 |
| 实施阶段 | 进度报告、质量报告、变更文件 |
| 验收阶段 | 验收报告、测试报告 |
| 运行维护阶段 | 运维记录、问题报告 |

### 2. 监理文档管理方法

#### 2.1 文档管理的作用

1. **满足业主单位需求**：使业主通过监理文档了解工程进展情况
2. **监理单位自身需要**：文档是监理工作成果的体现

#### 2.2 监理文档分类

| 文档类型 | 说明 |
|----------|------|
| **总控类文档** | 承建合同、设计方案、技术方案、项目组织实施方案、进度计划 |
| **监理日志** | 现场监理工作情况记录、当天大事、要事、资源投入 |
| **监理报告类** | 周报、月报、专题报告、总结报告、评估报告 |
| **监理回复类** | 监理单位收到工程文档后的回复/批复 |
| **会议纪要类** | 监理例会、专题会议纪要 |

#### 2.3 监理文件的内容与作用

| 文件类型 | 主要内容 | 作用 |
|----------|----------|------|
| **监理日志** | 现场工作情况、大事、要事、资源投入 | 记录监理过程，为索赔提供证据 |
| **周报** | 本周工程进展、问题、下周计划 | 向业主汇报工程进度 |
| **月报** | 总体进展、质量、进度、投资情况分析 | 全面反映项目状态 |
| **专题报告** | 特定问题的专项分析 | 针对重大问题的专门汇报 |
| **总结报告** | 项目整体情况、经验教训 | 项目结束后的全面总结 |

## 三、通俗例子

<Card title="信息分类例子" icon="information">
就像图书馆整理书籍：
- **按性质**：指导类（说明书）vs 辨识类（合格证）
- **按用途**：投资类（价格标签）vs 进度类（借阅记录）
- **按载体**：纸质书vs电子文档vs视频
- **按阶段**：新书上架→借阅中→归还→归档
</Card>

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **信息性质分类**：引导信息（指导行为）、辨识信息（认识特征）
2. **信息用途分类**：投资、进度、质量、合同、协调、其他
3. **信息载体分类**：文字、语言、符号图表、视频
4. **工程阶段分类**：招标、设计、实施、验收、运维
5. **监理文档类型**：总控类、日志、周报/月报、专题报告、总结报告

### 学习建议

- 信息的分类是考试重点，需要清晰区分各类别
- 建议用实际例子理解每种分类方法
- 监理文档管理是监理工作的重要内容，需要掌握各类文档的作用
