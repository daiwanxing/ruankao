## 一、教学目标

掌握项目运行的组织环境，包括治理框架、管理要素和组织结构类型，理解PMO的作用和类型。

## 二、核心讲解

### 1. 治理框架

**治理**是在组织各层级上的组织性或结构性安排，旨在确定和影响组织成员的行为。

<Card title="治理框架内容" icon="star">

1. 规则、政策、程序、规范
2. 关系、系统和过程
3. 影响范围：组织目标实现方式、风险监控评估方式、绩效优化方式

</Card>

### 2. 管理要素

| 要素 | 说明 |
|------|------|
| 部门 | 基于专业技能及其可用性开展工作 |
| 工作职权 | 组织授予的工作职权 |
| 工作职责 | 合理分派的工作任务 |
| 行动纪律 | 尊重职权、人员和规定 |
| 统一指挥 | 一项行动仅由一个人发布指示 |
| 统一领导 | 一组活动只有一份计划或一个领导 |
| 总体目标 | 优先于个人目标 |
| 薪酬 | 支付合理的薪酬 |
| 资源优化 | 资源的优化使用 |
| 沟通 | 畅通的沟通渠道 |
| 公正平等 | 公正、平等对待所有员工 |
| 安全 | 确保员工安全 |

### 3. 组织结构类型

| 组织结构 | 项目特征 | 项目经理权力 | 资源可用性 |
|----------|----------|--------------|------------|
| **职能型** | 按职能划分 | 极少或无 | 极少或无 |
| **矩阵型-强** | 按职能/项目 | 中到高全职 | 中到高 |
| **矩阵型-弱** | 兼职 | 低 | 低到中 |
| **矩阵型-均衡** | 嵌入职能 | 低到中兼职 | 低到中 |
| **项目导向型** | 项目 | 高到几乎全部全职 | 高到几乎全部 |
| **虚拟网络型** | 节点联系 | 低到中 | 低到中混合 |
| **PMO型** | 集中管理 | 高到几乎全部 | 高到几乎全部 |

### 4. 项目管理办公室（PMO）

**PMO**是对与项目相关的治理过程进行标准化，并促进资源、方法论、工具和技术共享的组织结构。

#### PMO类型

| 类型 | 控制程度 | 特点 |
|------|----------|------|
| **支持型** | 低 | 担当顾问角色，提供模板、最佳实践、培训 |
| **控制型** | 中等 | 要求服从框架/方法论，使用特定模板工具 |
| **指令型** | 高 | 直接管理和控制项目，项目经理由PMO指定 |

#### PMO主要职能

1. 共享资源管理
2. 识别和制定项目管理方法、最佳实践和标准
3. 指导、辅导、培训和监督
4. 项目审计，监督合规性
5. 制定和管理项目政策、程序、模板
6. 跨项目沟通协调

## 三、通俗例子

<Card title="组织结构例子" icon="information">
就像不同类型的公司：
- **职能型**：按部门划分（研发部、市场部）
- **矩阵型**：员工同时向职能经理和项目经理汇报
- **项目导向型**：为项目成立专门团队
- **PMO**：公司的项目管理中心，统一管理所有项目
</Card>

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **治理框架**：规则、政策、程序、规范、关系、系统和过程
2. **组织结构类型**：职能型、矩阵型（弱/均衡/强）、项目导向型、虚拟网络型、PMO
3. **PMO类型**：支持型（低控制）、控制型（中等）、指令型（高控制）
4. **PMO职能**：资源管理、制定标准、培训监督、审计合规

### 学习建议

- 理解不同组织结构对项目管理的影响
- 掌握PMO的定位和类型区别
- 了解治理框架的组成要素
