## 一、教学目标

掌握项目的基本概念（独特性、临时性）、项目管理的定义以及项目成功的评判标准。

## 二、核心讲解

### 1. 项目的基础概念

**项目**是人们通过努力，运用各种方法，将人力、材料和财务等资源组织起来，根据商业模式的相关策划安排，进行的一项独立一次性或长期无限期的工作任务，以期达到由数量和质量指标所限定的目标。

#### 项目的三大特征

| 特征 | 说明 | 理解要点 |
|------|------|----------|
| **独特性** | 独特的产品、服务或成果 | 每个项目需求、设计、干系人都是独特的 |
| **临时性** | 有明确的起点和终点 | 项目可宣告结束：达成目标/无法达到目标/资金耗尽/需求不存在 |
| **驱动变更** | 从当前状态转到将来状态 | 项目推动组织获得更高业务价值 |

<Card title="项目临时性的结束条件" icon="star">

1. 达成项目目标
2. 不会或不能达到目标
3. 项目资金耗尽或不再获得资金支持
4. 对项目的需求不复存在
5. 无法获得所需的人力或物力资源
6. 出于法律或其他原因终止项目

</Card>

### 2. 项目创造业务价值

| 价值类型 | 举例 |
|----------|------|
| **有形效益** | 货币资产、股东权益、公共事业、固定资产、工具、市场份额 |
| **无形效益** | 商誉、声誉、商标、公共利益、战略联盟、品牌认知度、工作效率 |

### 3. 项目启动背景

| 类别 | 示例 |
|------|------|
| **符合法律法规或社会需求** | 法律要求、环保需求 |
| **满足干系人要求或需求** | 客户要求、用户需求 |
| **创造、改进或修复产品/过程/服务** | 技术升级、业务过程改进 |
| **执行、变更业务或技术战略** | 战略转型、新技术应用 |

### 4. 项目成功的标准

**传统指标**：时间、成本、范围和质量

<Card title="项目成功的标准" icon="star">

1. 完成项目效益管理计划
2. 达到可行性研究中记录的财务测量指标（NPV、ROI、IRR、PBP、BCR）
3. 达到可行性研究的非财务目标
4. 组织从"当前状态"成功转移到"将来状态"
5. 履行合同条款和条件
6. 达到组织战略、目的和目标
7. 使干系人满意
8. 可接受的客户/最终用户的采纳度
9. 将可交付成果整合到组织的运营环境中
10. 满足商定的交付质量
11. 遵循治理规则

</Card>

## 三、通俗例子

<Card title="项目例子" icon="information">
就像开发一个信息系统：
- **独特性**：每个系统需求、设计都不同，即使是相似的系统
- **临时性**：有明确的项目周期，项目完成后团队解散
- **驱动变更**：项目使组织从"没有系统"变成"有系统"
</Card>

| 知识点 | 关键要点 |

| **项目结束条件** | 目标达成/无法达成/资金耗尽/需求消失 |

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **项目三大特征**：独特性、临时性、驱动变更
2. **项目结束条件**：目标达成/无法达成/资金耗尽/需求消失/资源缺乏/法律原因
3. **业务价值类型**：有形效益（货币资产、市场份额）、无形效益（商誉、品牌）
4. **成功标准**：时间、成本、范围、质量、干系人满意等

### 学习建议

- 理解项目的本质特征是项目管理的基础
- 掌握项目结束的几种情况
- 了解项目成功标准的多维度考量
