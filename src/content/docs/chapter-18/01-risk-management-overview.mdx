## 一、教学目标

掌握风险的基本概念、风险的分类以及风险管理的重要性。

## 二、核心讲解

### 1. 风险的概念

**风险**是项目生命周期中由于各种内外部因素导致项目无法按照计划实施、达到预期目标或满足相关质量要求的不确定性。

<Card title="风险的两个核心属性" icon="star">

1. **概率**：某一事件发生的可能程度
2. **影响**：风险产生的后果（可能是消极的威胁，也可能是积极的机会）

</Card>

### 2. 风险的分类

| 风险类型 | 说明 | 举例 |
|----------|------|------|
| **技术风险** | 技术和工具导致的问题 | 技术不成熟、兼容性问题、技术选型错误 |
| **需求变更风险** | 客户修改需求导致的问题 | 进度延期、成本增加、质量下降 |
| **人力资源风险** | 团队成员问题 | 离职、招聘困难、合作问题 |
| **管理风险** | 管理措施和决策问题 | 沟通不畅、组织结构不合理、决策失误 |
| **合同风险** | 合同内容问题 | 条款不明确、未履行约定 |
| **质量风险** | 质量不满足预期 | 客户不满意、返工 |
| **成本风险** | 成本超出预算 | 资源浪费、经济效益受损 |
| **进度风险** | 交付延误 | 未按计划完成 |
| **法律和政策风险** | 法律法规变更 | 政策变化影响项目 |
| **外部环境风险** | 外部因素影响 | 自然灾害、市场竞争 |

### 3. 风险管理的重要性

| 重要性 | 说明 |
|--------|------|
| **降低决策错误概率** | 通过风险管理识别风险，避免错误决策 |
| **避免可能的损失** | 提前识别风险，采取措施避免损失 |
| **提高监理质量** | 良好的风险管理有助于提高监理质量 |

<Card title="风险管理的定义" icon="information">
风险管理是指如何在一个肯定有风险的环境里把风险可能造成的不良影响减至最低的管理过程。
</Card>

## 三、通俗例子

<Card title="风险管理例子" icon="information">
就像开车出行：
- **风险识别**：天气、路况、车况
- **风险评估**：下暴雨危险、爆胎危险
- **风险应对**：带伞、备胎、买保险
- **风险监控**：实时关注天气、路况
</Card>

## 四、知识点速记

| 知识点 | 关键要点 |
|--------|----------|
| **风险定义** | 不确定性，可能威胁或带来机会 |
| **风险属性** | 概率 + 影响 |
| **十大风险** | 技术、需求变更、人力资源、管理、合同、质量、成本、进度、法律政策、外部环境 |
| **风险管理目标** | 降低损失、提高效益 |

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **风险概念**：不确定性，概率+影响
2. **风险分类**：技术、需求变更、人力资源、管理、合同、质量、成本、进度、法律政策、外部环境
3. **风险属性**：概率（可能性）、影响（威胁或机会）
4. **风险管理目标**：降低损失、提高效益

### 学习建议

- 掌握风险的定义和属性
- 记住十大风险类型，可用口诀"技术需求人管理，合同质成进法外"
- 理解风险管理的重要性
