## 一、教学目标

掌握项目风险管理的五个主要过程：风险规划、风险识别、风险分析、风险应对、风险监控。

## 二、核心讲解

### 1. 风险管理过程概述

<Card title="风险管理五大过程" icon="star">

1. **风险规划**：定义如何实施项目风险管理活动
2. **风险识别**：识别单个及整体项目风险的来源
3. **风险分析**：评估风险概率和影响，确定优先级
4. **风险应对**：选择应对策略并商定应对措施
5. **风险监控**：监督风险应对计划实施，跟踪已识别风险

</Card>

### 2. 风险规划

**目的**：建立风险管理过程，为项目制定整体风险管理策略

#### 主要依据

| 依据 | 说明 |
|------|------|
| 项目管理计划 | 范围、进度、沟通、成本计划 |
| 组织过程资产 | 风险态度、历史数据、经验教训 |
| 项目干系人 | 风险偏好、容忍度 |

#### 风险规划原则

| 原则 | 说明 |
|------|------|
| **全面性** | 考虑各阶段各类风险 |
| **灵活性** | 能根据实际变化调整 |
| **职责明确性** | 明确人员与职责 |

### 3. 风险识别

**目的**：识别项目风险来源，记录风险特征

#### 常用方法

- 头脑风暴
- 德尔菲法
- 检查表法
- SWOT分析
- 假设分析

### 4. 风险分析

| 分析类型 | 说明 |
|----------|------|
| **定性分析** | 评估概率和影响，确定优先级排序 |
| **定量分析** | 统计可量化数据，建立数学模型分析 |

### 5. 风险应对

| 策略 | 说明 |
|------|------|
| **规避** | 改变计划消除风险 |
| **转移** | 将风险转移给第三方 |
| **减轻** | 采取措施降低概率或影响 |
| **接受** | 承认风险，不采取措施 |

### 6. 风险监控

**内容**：
- 监督风险应对计划实施
- 跟踪已识别风险
- 识别和分析新风险
- 评估风险管理有效性

## 三、通俗例子

<Card title="风险管理过程例子" icon="information">
就像预防感冒：
- **风险规划**：制定预防感冒的计划
- **风险识别**：识别可能感冒的原因（受凉、病毒）
- **风险分析**：评估各种原因的严重程度
- **风险应对**：多穿衣服、戴口罩、锻炼身体
- **风险监控**：关注天气变化、身体状况
</Card>

## 四、知识点速记

| 知识点 | 关键要点 |
|--------|----------|
| **五大过程** | 规划、识别、分析、应对、监控 |
| **风险规划依据** | 项目管理计划、组织过程资产、干系人 |
| **风险规划原则** | 全面性、灵活性、职责明确 |
| **风险分析** | 定性分析（概率/影响）、定量分析（数据/模型） |
| **应对策略** | 规避、转移、减轻、接受 |

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **五大过程**：规划→识别→分析→应对→监控
2. **风险规划依据**：项目管理计划、组织过程资产、干系人
3. **风险规划原则**：全面性、灵活性、职责明确性
4. **风险分析类型**：定性分析（概率/影响）、定量分析
5. **应对策略**：规避、转移、减轻、接受

### 学习建议

- 掌握风险管理过程的顺序
- 理解每个过程的主要内容和目的
- 记住四大风险应对策略
