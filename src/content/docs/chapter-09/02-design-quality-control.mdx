## 一、教学目标

掌握设计阶段质量控制的内容、方法和评审要点。

## 二、质量控制内容

### 1. 招标阶段质量控制要点

<MemoryCard
  title="招标阶段质量控制"
  formula="需求方案→招标文件→评定标准→评标审查→合同洽商"
  importance={5}
  category="formula"
/>

招标阶段是质量控制的起点，监理单位应协助业主单位做好以下质量控制工作：

| 序号 | 控制要点 | 具体内容 |
|------|----------|----------|
| 1 | 协助业主单位提出工程需求方案 | 确定工程整体质量目标 |
| 2 | 参与招标文件编制 | 确保质量要求在招标文件中明确体现 |
| 3 | 协助制定投标文件的质量评定标准 | 建立科学的质量评价体系 |
| 4 | 对招标文件进行审核 | 检查质量要求的完整性和合理性 |
| 5 | 评标时审查投标文件中的质量控制计划 | 评估承建单位的质量保证能力 |
| 6 | 审核承建单位及其人员能力 | 确保承建单位具备相应的资质和能力 |
| 7 | 对招标过程进行监督 | 确保招标过程公开、公平、公正 |
| 8 | 协助业主与中标单位洽商并签订承建合同 | 将质量要求落实到合同条款中 |

### 2. 设计阶段质量控制要点

**设计质量控制的重要性**：
设计阶段决定了工程质量的基础，设计缺陷会在后期被放大，修正成本极高。

**设计阶段质量控制内容**：

| 序号 | 质量控制要点 | 具体内容 |
|------|--------------|----------|
| 1 | 协助业主制定项目质量目标规划 | 明确项目整体质量目标和质量标准 |
| 2 | 对各种设计文件提出设计质量标准 | 确保设计文件符合规范要求 |
| 3 | 审查阶段性设计成果，及时发现质量问题 | 在设计各阶段进行质量把关 |
| 4 | 审查承建单位提交的设计方案 | 验证设计方案的合理性和可行性 |
| 5 | 审查承建单位对关键部位的测试方案 | 确保测试方案覆盖关键质量点 |
| 6 | 审查承建单位的质量管理体系 | 确保质量体系能有效运行 |
| 7 | 组织设计文件及设计方案交底会 | 确保各方充分理解设计意图 |
| 8 | 设计方案经监理审定后由总监签发 | 确保设计方案经过正式批准 |
| 9 | 设计方案未经批准不得部署实施 | 严格控制设计变更和实施启动 |

**分阶段质量控制内容**：

| 阶段 | 质量控制要点 |
|------|--------------|
| **需求分析阶段** | 需求完整性、可行性、一致性 |
| **概要设计阶段** | 体系架构、模块划分、接口设计 |
| **详细设计阶段** | 算法设计、数据结构、界面设计 |

### 2. 设计评审

**设计评审类型**：

| 评审类型 | 评审内容 | 评审人员 |
|----------|----------|----------|
| **需求评审** | 需求的完整性、正确性、可追溯性 | 业主、监理、承建单位 |
| **设计评审** | 设计的合理性、可行性、标准符合性 | 技术专家、业主代表 |
| **代码评审** | 代码规范性、可读性、效率 | 技术专家、开发人员 |

**设计评审要点**：

| 评审维度 | 检查内容 |
|----------|----------|
| **完整性** | 功能是否完整覆盖需求 |
| **正确性** | 设计方案是否正确可行 |
| **一致性** | 各模块之间是否协调一致 |
| **标准符合性** | 是否符合技术标准和规范 |
| **可维护性** | 设计是否便于后期维护 |
| **可扩展性** | 设计是否支持功能扩展 |

### 3. 设计质量控制方法

| 方法 | 说明 |
|------|------|
| **审查** | 审查设计文档的完整性和正确性 |
| **验证** | 验证设计方案是否满足需求 |
| **确认** | 确认设计方案的可行性和合理性 |
| **评审** | 组织专家对设计方案进行评价 |

## 三、通俗例子

<Card title="设计评审例子" icon="information">
就像建房子前的图纸审查：
- 检查图纸是否完整（有没有少画房间）
- 检查设计是否合理（承重墙位置对不对）
- 检查是否符合规范（防火通道够不够宽）
- 检查能不能建出来（技术能不能实现）
</Card>

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **设计三阶段**：需求分析、概要设计、详细设计
2. **设计评审三类型**：需求评审、设计评审、代码评审
3. **评审六要点**：完整性、正确性、一致性、标准符合性、可维护性、可扩展性
4. **质量控制四方法**：审查、验证、确认、评审
