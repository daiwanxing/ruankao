## 一、教学目标

掌握数据中心的基本概念和主要建设任务。

## 二、核心讲解

### 1. 数据中心基本概念

**数据中心**是以信息技术为支撑，由电子设备机房、其他基础设施、信息系统软硬件、信息资源(数据)和人员及规章制度组成的，以实现应用集中处理和数据集中存放的基础环境。

### 2. 数据中心建设任务

| 建设任务 | 主要内容 |
|----------|----------|
| **电子设备机房** | 供配电、空调、消防、安防、环境监控 |
| **基础设施** | 机房装修、布线、接地、防雷 |
| **信息系统** | 服务器、存储、网络、软件 |
| **信息资源** | 数据整合、交换、共享 |

### 3. 基本概念

| 概念 | 说明 |
|------|------|
| 设计交底 | 设计单位向承建单位、监理单位说明施工图 |
| 深化设计 | 结合现场实际情况细化图纸 |
| 上电自检 | 设备接通电源后的自我检查 |
| SLA | 服务级别协议 |
