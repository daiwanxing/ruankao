## 一、教学目标

掌握监理组织协调工作的方法，包括监理会议的组织原则、项目监理例会的主要议题和专题会议的类型。

## 二、核心讲解

### 1. 监理组织协调工作的目标与方法

**目标**：使项目各方充分协作，有效地执行承建合同

**主要方法**：
- 监理会议
- 监理报告
- 沟通协调

### 2. 监理会议

#### 2.1 会议成功的关键原则

| 原则 | 说明 |
|------|------|
| **确保每个人到场** | 把会议作为每个人日程的固定项目 |
| **议程恰当** | 议程项目保持在所需的最低数量 |
| **领导与会** | 领导与会确保会议结果得到落实 |

#### 2.2 确保会议成功的措施

**会前准备**：
- 确定会议目的（交流信息、计划、收集情况、制定决策、解决问题、评估进展）
- 确定参会人员和会议议程
- 事先分发会议议程表

**会议过程把握**：
- 准时开始会议
- 指定记录员详细记录
- 确保会议效率
- 会议要达成预期结果或形成会议决议
- 尽量不要超过计划时间

**会议结果落实**：
- 会后24小时之内形成会议纪要
- 明确所做出的决定性意见，列出行动细目（负责落实单位、负责人、时限要求）

### 3. 项目监理例会

**项目监理例会**是由工程监理单位总监理工程师组织与主持的例行工作会议。

**参会人员**：
- 总监理工程师、总监理工程师代表、相关监理工程师
- 承建单位项目经理、技术负责人及有关专业技术人员
- 业主单位驻现场代表人员
- 根据需要邀请设计单位、分包单位等

<Card title="项目监理例会主要议题" icon="star">

1. 检查和通报项目进度计划完成情况
2. 通报项目实施质量的检查情况
3. 检查上次会议议定事项的落实情况
4. 分包单位的管理和协调问题
5. 项目款支付的核定及财务支付中的有关问题
6. 接收和审查承建单位提交的相关项目文档
7. 监理提交相关监理文档
8. 解决项目变更的相关事宜
9. 违约、工期、费用索赔的意向及处理情况
10. 解决需要协调的其他有关事项

</Card>

### 4. 监理专题会议

**专题会议**是为解决专门问题而召开的会议，由总监理工程师或授权监理工程师主持。

| 会议类型 | 说明 |
|----------|------|
| **技术讨论会** | 讨论技术方案、技术难点 |
| **现场协调会** | 解决工作过程中的相互配合问题 |
| **紧急事件协调会** | 处理突发性变更事件 |
| **技术评审会** | 评审阶段成果 |

## 三、通俗例子

<Card title="会议组织例子" icon="information">
就像组织项目进度会：
- **会前**：确定目的、通知参会人、准备议程
- **会中**：准时开始、做好记录、达成决议
- **会后**：24小时内出纪要、明确责任人和时限
</Card>

## 四、知识点速记

| 知识点 | 关键要点 |
|--------|----------|
| **会议成功三原则** | 确保到场、议程恰当、领导与会 |
| **会议三阶段** | 会前准备、会议过程、会议落实 |
| **监理例会主持** | 总监理工程师 |
| **例会十大议题** | 进度、质量、变更、付款、索赔等 |
| **专题会议类型** | 技术讨论会、现场协调会、紧急协调会、评审会 |

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **会议组织三原则**：确保到场、议程恰当、领导与会
2. **会议纪要时间**：24小时内形成
3. **监理例会主持人**：总监理工程师
4. **例会十大议题**：进度、质量、变更、付款、索赔、分包、文档等
5. **专题会议类型**：技术讨论会、现场协调会、紧急协调会、评审会

### 学习建议

- 监理会议是组织协调的重要方法，需要掌握会议组织原则
- 项目监理例会是常考点，需记住例会的主要议题
- 了解专题会议的类型和适用场景
