## 一、教学目标

掌握组织协调的基本概念、系统内部协调与系统外部协调的内容，理解协调在项目管理中的重要性。

## 二、核心讲解

### 1. 组织协调的概念

**协调**是指联结、联合、调和所有的活动及力量，使工程各方配合得当，促使工程各方协同一致，实现预定的工程目标。

<Card title="组织协调的定义" icon="information">
在项目管理中，协调或协调管理称为"界面管理"，即主动协调相互作用的若干系统间能量、物质和信息的交换，以实现系统目标的活动。
</Card>

### 2. 组织协调的对象

信息系统工程建设项目作为一个系统，组织协调的对象可分为：
- **系统内部的协调**
- **系统外部的协调**

### 3. 系统内部的协调

系统内部协调主要包括三个方面：

| 协调类型 | 说明 | 协调方法 |
|----------|------|----------|
| **人际关系协调** | 调动内部各个组成部分的积极性 | 良好沟通、相互信赖 |
| **组织关系协调** | 使各项目组从整体目标出发完成本组工作 | 工作例会、业务碰头会、会议纪要、信息传递卡 |
| **需求关系协调** | 人员、材料、硬件设备、软件需求平衡 | 内部资源合理配置 |

### 4. 系统外部的协调

系统外部协调分为两类：

#### 4.1 具有合同因素的协调

| 协调关系 | 说明 |
|----------|------|
| 业主单位与承建单位 | 合同执行中的各种矛盾，监理应公正协商 |
| 业主单位与设计单位 | 设计过程的需求协调 |
| 业主单位与供应商 | 设备材料供应协调 |
| 总包与分包商 | 分包关系协调 |

#### 4.2 非合同因素的协调

涉及社会团体、新闻媒体、服务单位、金融机构等虽无合同关系但对项目有影响的单位。

| 协调对象 | 作用 |
|----------|------|
| 社会团体 | 社区关系、政府主管部门 |
| 金融服务机构 | 银行资金结算、拨付 |
| 媒体 | 舆论宣传、危机处理 |
| 服务单位 | 配套服务支持 |

<Card title="非合同因素协调的重要性" icon="star">
非合同因素的协调涉及范围更广，遇到问题更多，监理单位的协调工作量更大、更复杂。这些工作仅靠监理单位难以有效进行，需要各有关管理部门和业主单位的大力配合。
</Card>

## 三、通俗例子

<Card title="组织协调例子" icon="information">
就像组织一场演出：
- **人际关系协调**：导演与演员、演员与演员之间的沟通配合
- **组织关系协调**：舞台组、灯光组、音响组、化妆组的配合
- **需求关系协调**：演员数量、设备需求、场地需求的平衡
- **外部协调**：与场地方、消防部门、媒体的关系
</Card>

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **组织协调概念**：联结、联合、调和，使各方协同一致
2. **系统内部协调**：人际关系、组织关系、需求关系
3. **系统外部协调**：合同因素（业主-承建/设计/供应商）、非合同因素（社会团体、金融机构、媒体）
4. **协调方法**：工作例会、会议纪要、信息传递卡

### 学习建议

- 组织协调是监理工作的重要内容，需要理解各类协调关系
- 区分合同因素和非合同因素的协调对象
- 重点掌握系统内部三大协调内容
