## 一、教学目标

掌握运行维护监理的基本概念和主要工作内容。

## 二、核心讲解

### 1. 运行维护基本概念

**信息系统运行维护**是新建或升级改造类信息化项目实施完成后，在结束试运行周期、完成项目验收手续、正式进入生产环境交付使用阶段的维护和保养工作。

### 2. 运行维护服务对象

| 类型 | 内容 |
|------|------|
| **基础设施** | 综合布线、机房、网络设备、服务器、存储、系统软件 |
| **应用软件** | 通用软件、行业应用软件 |
| **数据** | 结构化数据、非结构化数据 |
| **信息安全** | 咨询、实施、培训 |

### 3. 运行维护监理类型

| 类型 | 说明 |
|------|------|
| 例行操作监理 | 日常预定工作的监理 |
| 响应支持监理 | 服务请求或故障申报的即时处理 |
| 优化改善监理 | 功能和性能调优工作 |
| 调研评估监理 | 调查研究或分析评价工作 |

### 4. 运行维护监理与建设监理对比

| 方面 | 建设监理 | 运行维护监理 |
|------|----------|--------------|
| 阶段 | 规划、设计、实施、验收 | 运行期间 |
| 重点 | 质量/进度/投资控制 | 可用性/性能/安全 |
| 周期 | 项目周期 | 长期持续 |
| 验收 | 一次性验收 | 持续评估 |

## 四、重点总结

### 本节必记考点 ⭐⭐⭐

1. **运行维护对象**：基础设施、应用软件、数据、信息安全
2. **监理四类型**：例行操作、响应支持、优化改善、调研评估
3. **与建设监理区别**：阶段不同、重点不同、周期不同
