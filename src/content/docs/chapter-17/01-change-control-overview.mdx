## 一、教学目标

掌握工程变更的基本概念、引起变更的原因、变更的影响以及变更的分类。

## 二、核心讲解

### 1. 工程变更的概念

**工程变更**是指在工程项目实施过程中，按照承建合同或其他约定程序对工程的设计和实施做出的变更。变更是对任何正式受控的项目基准的修改。

<Card title="项目基准" icon="star">
项目基准包括：经批准的可交付成果、项目文档、项目计划等工作产品。只有通过正式的变更控制程序才能进行变更。在项目基准确定之前，无须通过变更控制程序管理变更。
</Card>

### 2. 工程变更的原因

#### 主动变更 vs 被动变更

| 类型 | 说明 | 举例 |
|------|------|------|
| **主动变更** | 主动发起的变更，用于提高项目收益 | 减少投资、改进方案、提高便捷性 |
| **被动变更** | 因范围变化、异常、错误而调整 | 适应变化、纠正错误 |

#### 变更的八种原因

1. 项目外部环境变化（法律法规、行业标准、政策变化）
2. 发生风险事件
3. 业主单位自身原因造成业务流程变化
4. 承建单位调整设计方案或实施方案
5. 项目范围定义错误或遗漏
6. 项目需求分析、总体设计不够充分详细
7. 项目执行与基准不一致带来的被动调整
8. 使项目增值（新技术、新设计方案）

### 3. 工程变更的影响

| 影响方面 | 说明 |
|----------|------|
| **项目范围** | 导致范围变化，带来设计、实施、测试、验收等方案变化 |
| **进度、成本、质量** | 进度延迟或加快、成本增加或减少、质量降低或提高 |
| **生产要素需求** | 原材料、工具、设备等生产要素变化 |
| **组织和人员** | 组织机构和人员变化，需增加新技术人员 |
| **项目干系人** | 影响干系人利益 |

### 4. 工程变更的分类

#### 按性质分类

| 类型 | 说明 |
|------|------|
| **重大变更** | 对项目有重大影响 |
| **重要变更** | 有一定影响但非重大 |
| **一般变更** | 影响较小 |

#### 按迫切性分类

| 类型 | 说明 |
|------|------|
| **紧急变更** | 必须立即实施 |
| **非紧急变更** | 可按正常流程处理 |

## 三、通俗例子

<Card title="变更例子" icon="information">
就像装修房子：
- **变更原因**：业主改变想法、材料涨价、发现设计错误
- **变更影响**：预算增加、工期延长、效果变化
- **变更分类**：大变动（拆墙）、小改动（换颜色）、紧急抢修
</Card>

## 四、知识点速记

| 知识点 | 关键要点 |
|--------|----------|
| **工程变更** | 对项目基准的修改 |
| **变更原因** | 外部环境、风险、业主原因、承建调整、范围错误、设计不足 |
| **变更影响** | 范围、进度成本质量、生产要素、组织人员、干系人 |
| **变更分类** | 重大/重要/一般；紧急/非紧急 |

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **工程变更概念**：对项目基准的修改
2. **变更原因**：主动变更（提高收益）、被动变更（范围变化、错误）
3. **变更影响**：范围、进度成本质量、生产要素、组织人员、干系人
4. **变更分类**：按性质（重大/重要/一般）、按迫切性（紧急/非紧急）

### 学习建议

- 理解变更控制的重要性
- 掌握变更的分类方式
- 了解变更可能带来的各方面影响
