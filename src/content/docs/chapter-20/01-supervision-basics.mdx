## 一、教学目标

掌握信息系统工程各阶段（规划、设计、实施、验收）的监理基础工作。

## 二、核心讲解

### 1. 规划阶段监理工作

| 监理活动 | 说明 |
|----------|------|
| 协助构建信息系统架构 | 基于业务入手，开展需求调研 |
| 提供规划咨询服务 | 可行性研究、初步设计咨询 |
| 审查需求和设计方案 | 审查是否符合法律法规和标准 |
| 协助策划招标方法 | 拆包分包策略、评标约定 |

### 2. 设计阶段监理工作

| 监理活动 | 说明 |
|----------|------|
| 审查设计方案 | 技术方案可行性、完整性 |
| 参与设计评审 | 组织专家论证 |
| 审查设计计划 | 进度、资源安排 |

### 3. 实施阶段监理工作

| 监理活动 | 说明 |
|----------|------|
| 质量控制 | 检查材料、工艺、测试 |
| 进度控制 | 跟踪计划执行情况 |
| 投资控制 | 审核工程量、进度款 |
| 变更控制 | 评估变更影响 |

### 4. 验收阶段监理工作

| 监理活动 | 说明 |
|----------|------|
| 初验监理 | 检验系统功能性能 |
| 试运行监理 | 跟踪运行状况 |
| 终验监理 | 最终验收确认 |
| 培训监理 | 监督培训实施 |

## 三、知识点速记

| 阶段 | 主要工作 |
|------|----------|
| 规划 | 架构设计、可行性研究、招标策划 |
| 设计 | 方案审查、专家评审 |
| 实施 | 质量/进度/投资/变更控制 |
| 验收 | 初验、试运行、终验 |

## 五、重点总结

### 本节必记考点 ⭐⭐⭐

1. **四阶段监理**：规划、设计、实施、验收
2. **规划阶段**：架构设计、可行性研究、招标
3. **实施阶段**：四控两管一协调
4. **验收阶段**：初验、试运行、终验
