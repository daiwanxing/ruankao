## 一、教学目标

掌握监理工作的具体内容、主要方法和工作流程。

## 二、核心讲解

### 1. 监理工作阶段划分

**监理工作贯穿项目全生命周期**：

| 项目阶段 | 监理工作内容 |
|----------|--------------|
| **项目决策阶段** | 可行性研究评审、项目建议书审核 |
| **设计阶段** | 设计方案评审、设计进度和质量管理 |
| **招标阶段** | 招标文件审查、招标过程监督 |
| **施工阶段** | 质量控制、进度控制、投资控制 |
| **验收阶段** | 验收测试组织、验收文档审核 |
| **运维阶段** | 运维服务质量监督 |

### 2. 监理工作方法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| **审核** | 审核各类文档、方案、报告 | 设计方案、进度计划等 |
| **检查** | 现场检查、巡视检查 | 工程质量、安全措施 |
| **试验** | 各类测试、检测 | 软件测试、设备检测 |
| **旁站** | 现场全程监督关键工序 | 隐蔽工程、关键节点 |
| **签认** | 对重要事项签字确认 | 验收签字、付款签认 |
| **协调** | 协调各方关系和争议 | 解决纠纷、统一意见 |

### 3. 监理主要工作

#### (1) 质量控制

| 控制阶段 | 控制内容 |
|----------|----------|
| **事前控制** | 审核承建单位资质、检查质量保证体系 |
| **事中控制** | 巡视检查、旁站监理、平行检验（监理机构利用一定的检查或检测手段，在承包单位自检的基础上，按照一定的比例独立进行检查或检测的活动） |
| **事后控制** | 验收测试、质量评估 |

#### (2) 进度控制

| 控制类型 | 具体措施 |
|----------|----------|
| **进度计划审核** | 审核项目进度计划的合理性和可行性 |
| **进度跟踪** | 定期检查实际进度与计划进度的偏差 |
| **进度调整** | 分析偏差原因，督促采取纠偏措施 |
| **进度报告** | 编制进度监理报告，向业主汇报 |

#### (3) 投资控制

| 控制环节 | 具体措施 |
|----------|----------|
| **投资审核** | 审核工程量清单、工程变更 |
| **投资监控** | 跟踪投资使用情况 |
| **投资支付** | 审核工程款支付申请 |
| **投资结算** | 审核工程结算报告 |

### 4. 监理工作流程

```
监理工作流程：
项目承接 → 组建监理部 → 编制监理规划 → 实施监理工作 → 监理资料整理 → 项目总结
    ↓           ↓              ↓              ↓              ↓             ↓
  签订合同   人员配置      制定计划     日常监理      归档资料      经验总结
```

### 5. 监理三文件

监理工作涉及三个重要文件，它们在不同阶段编制，详细程度和作用各不相同。

#### (1) 监理大纲

**定义**：监理大纲是监理单位在投标阶段编制的文件，是投标文件的重要组成部分。

<MemoryCard
  title="监理大纲"
  formula="编制阶段：投标阶段 | 编制人：企业技术负责人 | 作用：争取中标"
  importance={4}
  category="key-point"
/>

**编制依据**：

| 依据 | 说明 |
|------|------|
| **业主单位要求** | 业主单位对监理工作的要求（包括监理招标文件） |
| **服务质量体系** | 监理单位的服务质量管理体系 |
| **监理服务规范** | 监理及相关服务规范 |
| **法律法规标准** | 与工程及相关服务有关的法律、法规和技术标准规范 |

**编制流程**：

```
监理单位编制 → 监理单位技术负责人审核 → 监理单位法定代表人（或授权代表）书面批准
```

**主要内容**：

| 内容 | 说明 |
|------|------|
| **监理工作目标** | 明确质量、进度、投资控制目标 |
| **监理工作依据** | 列出相关法律法规、标准规范 |
| **监理工作范围** | 明确监理服务的范围和边界 |
| **项目监理机构** | 监理组织结构及人员配备 |
| **监理工作计划** | 各阶段监理工作安排 |
| **各阶段监理内容** | 详细的监理工作内容 |
| **监理流程和成果** | 监理工作流程及交付成果 |
| **监理服务承诺** | 对业主单位的服务承诺 |

**作用**：
- 展示监理单位的监理能力和水平
- 争取中标，获得监理业务
- 为后续监理工作制定框架方案

#### (2) 监理规划

**定义**：监理规划是在监理合同签订后、项目开始前编制的指导监理工作的纲领性文件。

<MemoryCard
  title="监理规划"
  formula="编制阶段：合同签订后 | 编制人：总监理工程师 | 作用：指导监理工作"
  importance={5}
  category="formula"
/>

**编制依据**：

| 依据 | 说明 |
|------|------|
| **法律法规及审批文件** | 与工程及相关服务有关的法律、法规及审批文件 |
| **监理法律法规** | 与信息系统工程监理有关的法律、法规及管理办法等 |
| **标准设计资料** | 与工程及相关服务有关的标准、设计文件和技术资料 |
| **合同文件** | 监理合同、承建合同、运维服务合同、工程及相关服务的其他文件 |

**编制流程**：

```
监理合同签订后 → 总监理工程师主持编制 → 监理单位技术负责人审批 → 报送业主单位确认后生效
```

**主要内容**：

| 内容 | 说明 |
|------|------|
| **工程概况** | 项目背景、建设规模、技术特点等 |
| **监理依据** | 法律法规、标准规范、合同文件等 |
| **监理范围** | 明确监理服务的具体范围 |
| **监理目标** | 质量、进度、投资控制目标 |
| **监理内容** | 各阶段具体监理工作内容 |
| **监理机构** | 监理组织结构及监理人员职责 |
| **监理设施** | 监理所需的设备、工具等 |
| **监理方法及措施** | 质量、进度、投资控制的方法和措施 |
| **监理工作制度** | 监理例会、报告、文档管理等制度 |

**作用**：
- 监理机构职能的具体体现
- 指导监理机构全面开展工作的纲领性文件
- 业主单位检查监理单位是否能够认真、全面履行监理合同的重要依据
- 具有合同效力的文件

#### (3) 监理实施细则

**定义**：监理实施细则是在监理规划基础上，针对专业监理工作编制的更详细、更具体的操作文件。

<MemoryCard
  title="监理实施细则"
  formula="编制阶段：项目实施初期 | 编制人：专业监理工程师 | 审批：总监理工程师"
  importance={5}
  category="formula"
/>

**编制依据**：

| 依据 | 说明 |
|------|------|
| **已批准的监理规划** | 以监理规划为基础进行细化 |
| **国家地方政策法规** | 与信息系统工程相关的国家、地方政策、法规和技术标准 |
| **设计文件技术资料** | 与信息系统工程相关的设计文件和技术资料 |
| **实施方案服务方案** | 工程实施方案及相关服务方案等与工程相关的文件 |
| **相关合同文件** | 承建合同、分包合同等相关合同文件 |

**编制流程**：

```
监理工程师依据监理规划编制 → 总监理工程师审批
```

**主要内容**：

| 内容 | 说明 |
|------|------|
| **工程特点** | 工程及相关服务的特点 |
| **监理工作流程** | 具体的监理工作流程和步骤 |
| **控制要点及目标** | 监理工作的控制要点及目标 |
| **监理方法及措施** | 具体的监理方法及措施 |

**作用**：

**对监理机构的作用**：
- 增加对本工程项目的认识程度，使监理人员更加熟悉工程的技术细节
- 作为指导监理工作开展的文件与备忘录

**对承建单位的作用**：
- 起到工作联系单或监理通知单的作用
- 起到提醒与警示作用

**对业主单位的作用**：
- 有利于业主单位对工程的管理和控制
- 有利于获得业主单位对监理的信任与支持

#### (4) 三文件对比

| 对比维度 | 监理大纲 | 监理规划 | 监理实施细则 |
|----------|----------|----------|--------------|
| **编制阶段** | 投标阶段 | 合同签订后 | 实施初期 |
| **编制人** | 技术负责人 | 总监理工程师 | 专业监理工程师 |
| **详细程度** | 粗略 | 较详细 | 最详细、最具体 |
| **审批人** | - | 技术负责人 | 总监理工程师 |
| **作用** | 争取中标 | 指导监理工作 | 指导具体实施 |

</Card>

## 六、重点总结

### 本节必记考点 ⭐⭐⭐⭐

1. **监理工作六方法**：审核、检查、试验、旁站、签认、协调
2. **质量控制三阶段**：事前控制（预防）、事中控制（监督）、事后控制（验收）
3. **进度控制四措施**：计划审核、跟踪、调整、报告
4. **监理工作流程**：项目承接→组建监理部→编制监理规划→实施监理工作→资料整理→项目总结
5. **监理三文件对比**：
   - 监理大纲：投标阶段、技术负责人编制、争取中标
   - 监理规划：合同签订后、总监理工程师编制、指导监理工作
   - 监理实施细则：实施初期、专业监理工程师编制、指导具体实施
6. **三文件编制人记忆**：大纲（技术负责人）、规划（总监）、细则（专业工程师）
