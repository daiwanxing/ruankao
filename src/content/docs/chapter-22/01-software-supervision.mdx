## 一、教学目标

掌握软件工程各阶段（招标、设计、实施、验收）的监理任务。

## 二、核心讲解

### 1. 软件工程基本概念

| 概念 | 说明 |
|------|------|
| 软件工程 | 应用计算机科学理论和技术以及工程管理原则和方法开发维护软件 |
| 单元测试 | 对软件中最小可测试单元进行检查验证 |
| 集成测试 | 将所有模块按设计要求组装成子系统或系统进行测试 |
| 系统测试 | 对整套系统进行测试，检验是否符合说明书 |
| 验收测试 | 部署软件前的最后一个测试阶段，也称交付测试 |

### 2. 软件工程监理四阶段13活动

| 阶段 | 监理活动 |
|------|----------|
| 招标阶段 | 招标准备的监理、招标的监理、合同签订的监理 |
| 设计阶段 | 计划制订的监理、需求分析的监理、概要设计的监理、详细设计的监理 |
| 实施阶段 | 编码及测试的监理、系统部署的监理 |
| 验收阶段 | 项目初验的监理、项目试运行的监理、项目终验的监理、培训的监理 |
